# KingQayumEditz portfolio

Static, responsive multi-page portfolio with no build step or package installation required. Open `index.html` in a browser to preview.

## Pages

- `index.html` — home and featured portfolio work
- `services.html` — six design services and process
- `portfolio.html` — artwork organized by category
- `about.html` — profile and tools listed on the formal website
- `contact.html` — confirmed contact details and an email-app form

## Contact form

The form validates the required fields and opens the visitor's default email application with the enquiry addressed to `kingqayumediting@gmail.com`. It does not submit to a server. A hosted form provider would be needed for direct website submission.
